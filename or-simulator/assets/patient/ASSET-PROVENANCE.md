# Virtual Patient Asset Provenance

The patient model and skeleton were carried forward from the prior Nabd Operations Studio prototype.

The source project notes identify the patient anatomy and adapted skin atlas as CC0 1.0. The model is a rigged GLB generated through the Khronos glTF Blender I/O pipeline. The previous prototype notes describe the source textures as `middleage_asian_male`, `brown_eye.png`, and `eyebrow001.png`, with privacy masking baked into the texture/mesh edition used by Nabd.

The rig includes separate finger bones for both hands. See `../../docs/patient-hand-rig.md` for the bone mapping used by v0.16.

This provenance note is based on the asset documentation embedded in the supplied v0.15 project. Keep the original CC0 attribution/provenance with the asset when redistributing the model.
