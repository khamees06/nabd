# v0.16 — Patient Hand Articulation & Developer Project

## User feedback addressed
- Patient hand/finger movement was missing from the visible controls.
- The trainee first-person hands were not appearing in the viewport.
- The user wants a maintainable project folder runnable from VS Code with Node.js tooling.

## Implementation
- Externalized GLB assets into `assets/`.
- Split HTML, CSS and the existing bundled Three.js engine.
- Added external GLB loading fallbacks for the patient, operating table, surgical light/pendant and anesthesia workstation.
- Added `scene.add(camera)` so camera-attached trainee hands participate in scene traversal and rendering.
- Moved trainee hand view-models closer to the camera.
- Added finger articulation controls for the patient GLB rig using its existing finger bones.
- Added left/right independent finger-curl sliders, open/close buttons, and a short demonstration animation.
- Added patient-hand values to the QA state.
- Kept the low-quality supervisor placeholder hidden.

## Validation
- JavaScript syntax check passed.
- GLB files extracted and verified to begin with the glTF binary magic `glTF`.
- Full visual review still requires running the project in a browser with WebGL 2 enabled.
