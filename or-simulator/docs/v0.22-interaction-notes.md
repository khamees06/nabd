# Nabd v0.22 — Interaction notes

## Learner control contract

- The learner chooses the work point on any visible, non-privacy-protected patient surface.
- The selected point remains the work target while the learner changes view direction or walks around the existing bed perimeter.
- **إعادة التركيز** returns the camera to the selected point without leaving the workstation.
- The surgical task lights follow the selected work point; this visual emphasis does not lock the camera.
- Camera look is independent: right mouse drag on desktop, or the **تغيير النظر** mode on touch devices.
- While a held object is in camera-look mode, its world-space grip is paused. The next manipulation input resumes object control.

## Patient contact

- General touch raycasts the patient surface on every pointer update, so the contact point follows the visible surface rather than a fixed horizontal plane.
- The face-level privacy filter uses the hit material index; it does not disable an entire multi-material skinned mesh when only one face group is protected.
- Finger-pad contact uses 3D proximity. The abdominal height-field and local deformation remain specialized to the anterior abdomen.

## Endoscope

- The selected abdominal work point is the virtual remote centre.
- The instrument is aligned before insertion. After insertion, pointer offset changes bounded pitch/yaw around the remote centre.
- Insertion is axial. Roll is independent.
- The tower screens display the same live WebGL render-target texture while the scope is inserted. When it is held but not inserted, the screens show NO SCOPE SIGNAL. They display **NO SCOPE SIGNAL** otherwise.
- Internal cavity/organ shapes are technical proxies only and are not clinically validated anatomy.
